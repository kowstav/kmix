New defects found and repaired or preserved:

- **CLI pagination:** success downloaded only the first 500 output files. The
  explicit next-page loop recovered all 609 files per constructor notebook;
  manifests and missing evidence were hash/CRC verified locally. Future collectors
  must require complete listing coverage, not merely a nonempty directory.
- **Word manifest schema:** `index` was assumed, but published regions use `id`.
  The original failed run was retained; version 2 asserts all required fields
  and exact ID set before computation and completed 16 regions.
- **Incomplete native source archive:** the older suffix filter omitted five
  required .hpp headers. The failed compilation exposed this; the corrected
  bundle includes their hashes and all 140 entries. The neutral executable
  rebuilt byte-identically, so current source restoration is substantiated.
- **PPMd real-data failure:** tiny tests were insufficient. Direct backend
  encode/decode fails on three real-page stress cases, with and without the
  outer container. Failure evidence is preserved. The root cause/repair remains
  open; no failed case is assigned a compression score. A native PPMd-H replacement
  subsequently completed all 160 paid cases with exact inverses. The selected
  graph still loses on confirmation; repaired execution is not a quality win.
- **Native preflight scope:** the helper deliberately truncates preflight=True
  to 16 KiB. The first packed-table gate used that flag despite claiming 64 KiB.
  Actual byte counts exposed the error. Original evidence was preserved, the
  label corrected, the dependent submitter held, and an explicit expected_bytes
  contract plus regression tests added. Corrected 64 KiB validation is separate;
  do not relabel the valid 16 KiB result as larger evidence.

The theory report also retains the audit's accepted corrections: parameter
optima are model-dependent, Lloyd–Max does not imply uniform occupancy, realized
bit-path entropy is not a before-byte feature, interactions can have either sign,
greedy directed ordering has no generic optimum guarantee, and gradient/rate
normalizations must match the actual final coder and package units.
