## 2. Corrections needed before interpreting learnability

**A high bit budget is an opportunity denominator, not recovered saving.** For a fixed causal cluster Z, H(Y|Z) describes a coarser predictor than one using the complete decoded prefix. Since Z is a deterministic function of that prefix, it supplies a constrained predictor with a representation, not new information. The existing coder can already do better than H(Y|Z) by using other prefix evidence. Conversely, a low plug-in entropy on a tiny or target-selected cluster is optimistic. Singletons have zero empirical entropy without offering free prediction. Charge estimation/cluster selection, use prefix or frozen assignments, and evaluate all activations and rejections.

**Compare the same outcome and conditioning.** A final bit probability, an observed multi-byte dictionary-code probability, a word probability conditional on being a word, and a gap probability with paid endpoints are different events. Do not subtract a conditional word entropy from a cost which also includes word/literal choice, casing, delimiters or alignment. Observed native code-path probabilities do not provide every counterfactual word probability. Complete support and normalization must be explicit.

**Do not activate a specialist using the current observed surprise.** c_t=-log2 p_t(y_t) includes the unknown outcome. It can be a training priority or an admission rule *after* a completed event. At inference the gate uses only decoded-prefix features, current native probabilities and already decoded bit prefixes. This is the distinction between the registered hard-memory admission and an invalid oracle which knows the next hard word.

For a cluster C use a provisional opportunity ledger

    E_C = sum_{t in C} [-log2 p_t(y_t)]
          - L_prequential_candidate(all outcomes in C)
          - L(cluster description, choices, coefficients and code).

The word “all” matters: false excitations, unmatched cases and ordinary easy occurrences are charged. Rank clusters by verified incremental gain per byte/CPU after a generic equal-capacity control. Empirical B_C - n_C*H_hat(Y|C) may guide inspection, but is not a reliable archive forecast or an absolute ceiling.

## 3. Weighted curriculum and objective drift

Repeating an example changes the summed objective like an integer loss weight. It does not generally reproduce the same SGD/Adam trajectory: batching, ordering, normalization, clipping, optimizer state and learning-rate schedule also change. Define the exact objective and schedule in useful target events.

For unweighted real-data risk J=E_P[-log q_theta(Y|H)] and sampling distribution r(t)>0, an unbiased estimator uses P(t)/r(t). Deliberately omitting that correction is a curriculum intervention and must be labeled as such. In an unconstrained categorical model, weighted loss has optimum

    q_w(y|h) proportional to P(y|h) * E[w | Y=y,H=h].

If expensive target outcomes receive larger weights, this generally raises their probabilities even when their true frequency is unchanged. A later unweighted phase may repair the distortion but does not guarantee repair in a finite nonconvex run. Freeze the diagnostic costs/weights during a phase; continually recomputing surprise while differentiating through it defines a different objective.

A useful bounded schedule is

    J_k = J_real + eta_k*J_synthetic + beta_k*R_package,

with eta declining to zero, and a separate paid-rate frontier over beta. Keep a lambda-zero real-data continuation control before attributing any gain to the synthetic or rate terms. Evaluate actual native coding, not merely the weighted training loss. The unchanged$70plan pays for a small controlled pilot first; no new spending has occurred.

## 4. Synthetic invariance needs its own causal/state contract

Changing nouns or conditions does not automatically preserve the correct target or its probability. Synthetic positives must teach the same prefix-visible relation; retain alternatives/negative cases and a null gate. A right endpoint is useful only in a codec which has decoded its paid representation first.

For the original transformer, a changed synthetic prefix requires consistent PPMd priors, tokenization, resets and prompt schedule. Original real-data priors cannot simply be reused under altered text. For an independent residual, changing a context feature while keeping an unrelated original native p can likewise create inconsistent training records. Either regenerate the corresponding native features, or use synthetic data only for a clearly separated auxiliary relation task, with final residual supervision entirely on real native records. Price any teacher, generated rule, retained table and exported student actually needed at execution.
